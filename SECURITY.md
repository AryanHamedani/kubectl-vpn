# Security policy

Only the latest release receives fixes.

Please do not open a public issue for a vulnerability. Use GitHub's private reporting: on the repository's **Security** tab choose **Report a vulnerability**.

The tunnel, firewall and proxy live in [sidetunnel](https://github.com/AryanHamedani/sidetunnel); report problems with those there. Report here anything about the `kubectl` wrapper, the installer, the kubeconfig changes or how credentials are stored.
